# Módulo de Escaneos de Folios — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Módulo `/escaneos/subir` para subir JPGs de folios escaneados a `<SCANS_FOLDER>/<año>/` y marcar `escaneado=True` en los folios cuyo número coincide con el nombre del archivo en ese año.

**Architecture:** Blueprint nuevo `app/escaneos/` con una ruta GET/POST, un form multi-archivo, y un servicio `guardar_y_matchear()` que escribe en disco y matchea `Folio` por `(anioCert, folio)`. Procesamiento síncrono por archivo dentro del request; un fallo por archivo no aborta el lote.

**Tech Stack:** Flask 3 + SQLAlchemy + Flask-WTF (MultipleFileField) + Jinja2/Bootstrap 5, pytest.

**Spec:** `docs/superpowers/specs/2026-10-07-escaneos-upload-design.md`

## Global Constraints

- Nombre de archivo estricto: regex `^(\d+)\.(jpg|jpeg)$` con `re.IGNORECASE`. Sin espacios, sin sufijos (`1000_copia.jpg` es inválido).
- El nombre en disco se **reconstruye** desde el número parseado (`<numero>.jpg`); el filename del cliente nunca toca el filesystem (anti path-traversal).
- Matching: `Folio.anioCert == año AND Folio.folio == número` → marcar **todos** los folios de ese año (cualquier tipo de certificado).
- Año de la subcarpeta: selector de form, choices = `Folio.anioCert` distinct (valor elegido manda, no el archivo ni la fecha).
- JPG sin match: se guarda igual y se reporta "Sin coincidencia"; no se marca nada.
- Archivo repetido: sobrescribe (no sufijo, no error).
- Reproceso por archivo: un error (nombre inválido, fallo de disco) no detiene el resto del lote.
- `MAX_CONTENT_LENGTH` (32 MB) no se toca; el handler 413 existente responde.
- Carpeta fuera de `app/static/` → nunca servible por HTTP.
- Todo texto de usuario en español.
- **Este repo NO es git**: en cada paso que dice "commit", corre `python3 -m pytest -q` como gate en su lugar.
- Comandos de test desde la raíz del proyecto: `venv/bin/python -m pytest` (o `python3 -m pytest` si el venv está activo).

## Review Focus

Condiciones que el spec implica pero que un implementador novato rompe; cada una tiene su test en la tarea dueña.

1. **Año inexistente o choices vacías** — POST con año fuera de `anioCert` distinct debe rechazarse sin escribir nada en disco. → Task 3: `test_subir_anio_inexistente_no_escribe`, `test_subir_sin_anio_no_escribe`.
2. **Permisos** — rol `lectura` sin grant debe ser redirigido; `operador` (`can_edit() == True`) debe pasar el permiso default `'edit'`. → Task 1: `test_permiso_escaneos_por_rol`; Task 3: `test_subir_sin_permiso_redirige`.
3. **Nombres hostiles** — `1000 copia.jpg`, `../../1000.jpg`, `abc.jpg`, `1000.png` no deben escribirse; `1000.JPG`/`1001.jpeg` sí se aceptan (case-insensitive, destino normalizado a `<numero>.jpg`). → Task 2: `test_servicio_nombres_invalidos_no_escriben`, `test_servicio_mayusculas_y_jpeg_aceptados`.
4. **Sobrescritura** — segundo upload del mismo número pisa el contenido. → Task 2: `test_servicio_sobrescribe`.
5. **Lote mixto no aborta** — 1 inválido + 1 sin match + 1 con match en el mismo request: los tres procesados, totales correctos. → Task 3: `test_subir_lote_mixto`.
6. **Auditoría solo al cambiar** — `log_audit` una vez por folio al pasar a `escaneado=True`; re-subir el mismo archivo no duplica logs. → Task 2: `test_servicio_audita_solo_cambio`.

```python
"""Guardado de JPG de folios escaneados y marcado en la DB.

Un fallo por archivo (nombre inválido, error de disco) no aborta el lote:
cada archivo se procesa de forma independiente y queda reportado.
"""

import re
from pathlib import Path

from flask import current_app

from app.extensions import db
from app.models.folio import Folio
from app.services.audit import log_audit

# Nombre estricto: solo dígitos + .jpg/.jpeg. El destino en disco se reconstruye
# desde el número parseado, así que el filename del cliente nunca toca el
# filesystem (no hay path traversal posible).
NOMBRE_RE = re.compile(r'^(\d+)\.(jpg|jpeg)$', re.IGNORECASE)

MARCADO = 'marcado'
SIN_COINCIDENCIA = 'sin_coincidencia'
NOMBRE_INVALIDO = 'nombre_invalido'
ERROR_GUARDAR = 'error_guardar'


def guardar_y_matchear(archivos, anio, user_id):
    """Guarda cada JPG en <SCANS_FOLDER>/<anio>/<numero>.jpg y marca los folios.

    `archivos`: lista de FileStorage (MultipleFileField).
    `anio`: año del selector del form (int) — manda sobre cualquier otra fecha.
    Devuelve el reporte:
      {'resultados': [{'nombre', 'numero', 'estado', 'folios'}],
       'marcados', 'sin_coincidencia', 'invalidos', 'errores'}
    """
    carpeta = Path(current_app.config['SCANS_FOLDER']) / str(anio)
    reporte = {'resultados': [], 'marcados': 0, 'sin_coincidencia': 0,
               'invalidos': 0, 'errores': 0}

    for archivo in archivos:
        nombre = archivo.filename or ''
        match = NOMBRE_RE.match(nombre)
        if not match:
            reporte['resultados'].append(
                {'nombre': nombre, 'numero': None, 'estado': NOMBRE_INVALIDO,
                 'folios': 0})
            reporte['invalidos'] += 1
            continue

        numero = int(match.group(1))
        try:
            carpeta.mkdir(parents=True, exist_ok=True)
            archivo.save(carpeta / f'{numero}.jpg')
        except OSError:
            reporte['resultados'].append(
                {'nombre': nombre, 'numero': numero, 'estado': ERROR_GUARDAR,
                 'folios': 0})
            reporte['errores'] += 1
            continue

        folios = Folio.query.filter_by(anioCert=anio, folio=numero).all()
        for folio in folios:
            if not folio.escaneado:
                log_audit(user_id, 'UPDATE', 'folios', folio.id,
                          {'escaneado': False}, {'escaneado': True})
                folio.escaneado = True
        if folios:
            db.session.commit()
            estado = MARCADO
            reporte['marcados'] += 1
        else:
            estado = SIN_COINCIDENCIA
            reporte['sin_coincidencia'] += 1
        reporte['resultados'].append(
            {'nombre': nombre, 'numero': numero, 'estado': estado,
             'folios': len(folios)})

    return reporte
```

```python
class EscaneoForm(FlaskForm):

    ])
```

Crear `app/escaneos/__init__.py`:

```python
from flask import Blueprint, render_template
from flask_login import current_user

from app.decorators import permiso_requerido
from app.escaneos.forms import EscaneoForm
from app.extensions import db
from app.models.folio import Folio
from app.services.escaneos import guardar_y_matchear

escaneos_bp = Blueprint('escaneos', __name__, url_prefix='/escaneos')


@escaneos_bp.route('/subir', methods=['GET', 'POST'])
# hacia='dashboard' (default): el blueprint no tiene index a donde redirigir.
@permiso_requerido('escaneos.subir')
def subir():
    form = EscaneoForm()
    # choices ANTES de validar: SelectField valida contra ellas.
    anios = [fila[0] for fila in
             db.session.query(Folio.anioCert).distinct()
             .order_by(Folio.anioCert.desc()).all()]
    form.anio.choices = [(a, str(a)) for a in anios]

    reporte = None
    if form.validate_on_submit():
        reporte = guardar_y_matchear(form.archivos.data, form.anio.data,
                                     current_user.id)
    return render_template('escaneos/subir.html', form=form, anios=anios,
                           reporte=reporte)
```
